# 📊 Customer Segmentation Using RFM Analysis Dashboard

An interactive **Power BI Customer Sales Analysis Dashboard** built using the AdventureWorks dataset. This project analyzes customer demographics, sales performance, customer details, and customer segmentation using **RFM Analysis**.

The dashboard provides meaningful insights into customer behavior and helps identify valuable customer segments based on their purchasing patterns.

---

## 🚀 Project Overview

The **Customer Sales Analysis Dashboard** is designed to provide a comprehensive analysis of customers and sales data.

The dashboard consists of three interactive pages:

- 👥 Customer Demographics
- 🎯 Customer Segmentation (RFM Analysis)
- 📋 Customer Details

Users can filter and explore customer and sales data using interactive visuals and slicers.

# 🎯 RFM Analysis

RFM Analysis is a customer segmentation technique based on three important factors:

### 🔹 Recency

Measures how recently a customer made a purchase.

**Higher importance:** Customers who purchased recently are more likely to engage again.

### 🔹 Frequency

Measures how often a customer makes purchases.

**Higher frequency:** Indicates loyal and engaged customers.

### 🔹 Monetary Value

Measures how much money a customer spends.

**Higher monetary value:** Indicates high-value customers.

Using these metrics, customers are grouped into meaningful segments such as **Champions, Loyal Customers, At Risk Customers, and Lost Customers**.
